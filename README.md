# 🧬 MammoScan AI – Breast Cancer Detection Using Deep Learning

MammoScan AI is an AI-based medical imaging project developed as part of a PFA.  
The objective of this project is to assist in the detection of breast cancer from mammographic images using Deep Learning techniques, especially Convolutional Neural Networks (CNN) and Transfer Learning.

This project focuses on image preprocessing, data augmentation, model training, and performance evaluation for medical image classification.

---

## 🚀 Project Overview

Breast cancer is one of the most common cancers affecting women worldwide. Early detection plays an important role in improving treatment success and survival rates.

MammoScan AI proposes a Deep Learning-based solution that analyzes mammographic images and classifies them into two categories:

- Benign
- Malignant

The system is developed for academic, research, and educational purposes.

---

## ✨ Key Features

- Upload and process mammographic medical images
- Image preprocessing using OpenCV
- Data augmentation to improve model generalization
- Breast cancer classification using CNN / DenseNet121
- Performance evaluation using classification metrics
- User-friendly interface for testing predictions

## 🧠 Deep Learning Approach

The model is based on CNN architecture and Transfer Learning using DenseNet121.

The workflow includes:

1. Image preprocessing and resizing
2. Data cleaning and organization
3. Data augmentation
4. Model training
5. Model evaluation
6. Prediction on new medical images

The model is evaluated using the following metrics:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion matrix

## 📦 Installation & Setup

### Prerequisites

Make sure you have installed:

- Python 3.10+
- Node.js
- npm
- Git

---

## Backend Setup

~~~bash
cd backend
python -m venv venv
~~~

Activate the virtual environment:

### Windows

~~~bash
venv\Scripts\activate
~~~

### Linux / macOS

~~~bash
source venv/bin/activate
~~~

Install dependencies:

~~~bash
pip install -r requirements.txt
~~~

Run the backend server:

~~~bash
uvicorn main:app --reload
~~~

---

## Frontend Setup

~~~bash
cd frontend
npm install
npm run dev
~~~
